# A simple full stack online store build with python and flask for a module project

## Libraries
1. Flask
2. Flask_sqlalchemy
3. Flask_login
4. Jinja (templating)

The ui is designed with Canonical's vanilla design system

## running
``` 
python -m venv .venv
source .venv/bin/activate
pip install -r requirments.txt
python main.py   
```
